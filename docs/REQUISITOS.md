# Requisitos preliminares — foodbridge-Prototipo

**Objetivo:** Protótipo de experiência de usuário do FoodBridge para doadores e organizações.

- RF-01: Disponibilizar navegação ou operação principal documentada.
- RF-02: Mostrar feedback claro para entradas inválidas e falhas.
- RF-03: Preservar fluxos e interfaces atualmente existentes.
- RNF-01: Manter componentes organizados e acessíveis.
- RNF-02: Não expor dados sensíveis, tokens ou chaves.
- RNF-03: Documentar dependências e testes por camada.

Esta lista é proposta inicial. Validar cada requisito com o fonte. Trata-se de protótipo UX; telas e dados simulados não representam API completa ou doações reais.
