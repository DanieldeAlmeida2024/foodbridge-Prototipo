# Guia de IA e desenvolvimento — foodbridge-Prototipo

Protótipo de experiência de usuário do FoodBridge para doadores e organizações.

1. Leia o README e os componentes client, server, package.json antes de alterar o código.
2. Preserve a stack React, TypeScript e Node.js e as APIs/rotas já existentes.
3. Distinga o que está implementado do que é mock, hipótese ou proposta.
4. Use nomes em português nas novas rotinas, sem quebrar contratos externos.
5. Não versionar senhas, chaves, dados reais nem artefatos gerados.
6. Teste alterações com npm run build e registre limitações.
7. Não alterar publicação ou produção sem revisão.

Atenção: Trata-se de protótipo UX; telas e dados simulados não representam API completa ou doações reais.
